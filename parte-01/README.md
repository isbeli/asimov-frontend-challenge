# 🌿 Positivus — Landing Page

> Recriação fiel da landing page **Positivus** a partir de um design no Figma, desenvolvida com **React + Tailwind CSS v4**.

---

## 🚀 Tecnologias

![React](https://img.shields.io/badge/React-19-61DAFB?style=flat-square&logo=react)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-v4-38BDF8?style=flat-square&logo=tailwindcss)
![Vite](https://img.shields.io/badge/Vite-8-646CFF?style=flat-square&logo=vite)

- **React 19** — componentização e reatividade
- **Tailwind CSS v4** — estilização utilitária com `@tailwindcss/vite`
- **Vite 8** — bundler rápido com HMR
- **Google Fonts** — tipografia Space Grotesk

## 📸 Seções Implementadas

| Seção            | Descrição                                 |
| ---------------- | ----------------------------------------- |
| **Navbar**       | Menu responsivo com hamburguer animado    |
| **Hero**         | Título, descrição, CTA e ilustração       |
| **Brands**       | Logos de marcas parceiras em grayscale    |
| **Services**     | Grid de cards com hover effects           |
| **CTA**          | Banner de chamada para ação               |
| **Case Studies** | Cases em grid escuro com divisores verdes |

## 🤖 Uso de IA no Desenvolvimento

### Ferramentas utilizadas

- **Claude** (Anthropic)
- **ChatGPT** (OpenAI)
- **GitHub Copilot**

### Em que etapas a IA ajudou mais

A IA foi essencial na geração da estrutura inicial dos componentes responsivos, configuração do Tailwind CSS v4 com Vite, resolução de conflitos entre versões de dependências e na definição de breakpoints responsivos para mobile, tablet e desktop.

### O que foi ajustado manualmente e por quê

Espaçamentos, tamanhos de fonte, border-radius e caminhos de imagens exigiram refinamento manual para corresponder fielmente ao Figma. A animação do menu hamburguer, hover effects nos cards e o overflow da imagem do CTA também foram ajustados manualmente para o acabamento visual correto.
